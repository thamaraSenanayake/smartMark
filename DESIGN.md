# DESIGN.md - SmartMark Assessment System

## Design Tokens & Palette
- Mode: Clean Light Theme with High-Contrast Dark Accents
- Primary Color: Deep Academic Navy (`#0F172A`)
- Brand Accent: Vivid Indigo / Electric Royal (`#4F46E5`)
- Success / Correct Answer: Emerald Green (`#10B981`) - Soft tinted backdrops (`#ECFDF5`)
- Error / Wrong Answer: Crimson Rose (`#F43F5E`) - Soft tinted backdrops (`#FFF1F2`)
- Warning / Needs Audit: Amber (`#F59E0B`)
- Neutral Canvas: Off-White (`#F8FAFC`)
- Card Containers: Pure White (`#FFFFFF`) with 1px border (`#E2E8F0`)

## Typography
- Font Family: "Inter", system-ui
- Headings: SemiBold / Bold, tight letter spacing
- Data / Numbers: Monospace font for marks and grade values

## Components
- Border Radius: 12px for mobile cards, 8px for web tables and metric cards
- Elevation: Subtle, flat border-first design with low-blur drop shadows
